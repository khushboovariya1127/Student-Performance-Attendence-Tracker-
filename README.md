# 🗃️ SQL Practice Project

> A hands-on MySQL project focused on relational database design, data management, and query-based analysis.

## ✨ Project Overview

This project contains SQL practice work for creating and managing a relational database. It demonstrates how related tables can be structured and queried to organize information and answer practical questions.
